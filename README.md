# eda-marketing-ab-testing-
Laboratory Work #1 — Exploratory Data Analysis of Marketing A/B Testing
# Лабораторна робота №1 — Оглядовий аналіз та візуалізація даних (EDA)

**Варіант:** №8  
**Датасет:** Marketing A/B Testing  
**Мова програмування:** Python  
**Формат звіту:** Jupyter Notebook / HTML

## Мета роботи

Дослідити структуру та якість маркетингових даних, побудувати візуалізації, проаналізувати зв'язки між ознаками та конверсією, порівняти експериментальну й контрольну групи та сформувати практичні рекомендації.

## Датасет

Джерело: [Marketing A/B Testing — Kaggle](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing)

Датасет містить 588 101 запис про користувачів, розподілених між двома групами:

- `ad` — користувачі експериментальної рекламної групи.
- `psa` — користувачі контрольної групи.

Цільова змінна — `converted`, яка показує факт конверсії.

## Основні результати

- Пропущених значень і дублікатів не виявлено.
- Загальна конверсія становить приблизно 2,52%.
- Конверсія групи `ad` — 2,55%, групи `psa` — 1,79%.
- Абсолютна різниця — 0,7692 відсоткового пункта.
- Відносна різниця — 43,09%.
- Різниця між групами статистично значуща (p < 0,001).

Також досліджено зв'язок кількості рекламних показів, дня та години найбільшої кількості показів із конверсією.

## Методи аналізу

Використано описову статистику, гістограми, KDE, boxplot, pairplot, кореляції Pearson і Spearman, χ²-тест, Cramér's V, VIF, логістичну регресію та порівняння пропорцій.

## Запуск проєкту

Потрібен Python та встановлені залежності з `requirements.txt`.

Створення віртуального середовища:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Встановлення залежностей:

```powershell
python -m pip install -r requirements.txt
```

Запуск Jupyter Notebook:

```powershell
python -m jupyter notebook report/lab_1.ipynb
```

Вхідний файл `data/marketing_AB.csv` повинен бути доступний за вказаним шляхом.

## Висновок

Проведений аналіз показав статистично значущу різницю конверсій між експериментальною та контрольною групами.

Водночас виявлені зв'язки між кількістю рекламних показів, часом та конверсією не доводять причинного впливу. Для ухвалення бізнес-рішень необхідно додатково враховувати рекламні витрати, доходи та результати контрольованих експериментів.

## Обмеження

Датасет не містить економічних показників, точного часу конверсії та детальних характеристик користувачів. Контрольна група значно менша за експериментальну, що обмежує точність окремих підгрупових оцінок.
